# CodeJump application icon

`AppIcon.png` is the selected transparent master image, generated with the built-in ImageGen tool. The app build derives standard macOS icon sizes using `sips` and packages them with `iconutil`; resizing does not change the artwork.

Prompt:

> Create one polished production macOS application icon for a developer utility named CodeJump. Square 1024x1024 canvas with real alpha transparency outside the icon. A centered macOS rounded-square tile occupies about 86% of the canvas, with consistent 7% transparent padding. Deep cobalt blue to electric azure subtle gradient tile, softly beveled rounded edges, restrained premium satin finish. In the center a single bold white glyph unifies source-code angle brackets and a diagonal up-right navigation arrow: a simple left chevron on the left, and a crisp arrow rising from lower center toward upper right like jumping from code into an editor. Thick rounded strokes, balanced negative space, distinctive readable silhouette at 16px, geometric and precise. Subtle depth only, no busy glass reflections, no decorative particles. Icon only, front-facing orthographic, no text, no letters, no wordmark, no mockup device, no desktop background, no multiple variants, no watermarks. Keep the composition elegant and minimal, use only cobalt/azure and white with a tiny soft cyan highlight.
